# Vivek — Embedded Systems & IoT Portfolio

A responsive personal portfolio website built with plain HTML and CSS.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment to complete. The site URL will be shown in Settings → Pages.

## Project images
The portfolio currently uses designed placeholder blocks for the project cards. To add the original IoT project photographs, create an `assets` folder, upload the project images there, and replace the placeholder blocks in `index.html` with image elements pointing to those files.

No personal portrait or profile-photo section is included.
